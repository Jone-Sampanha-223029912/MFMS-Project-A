# Municipal Financial Management System

## Course
PAP521S - Programming in Practice

## Project
Project A - Municipal Financial Management System

## Programming Language
ANSI C (C99)

## Development Environment
Visual Studio Code + GCC

## Version Control
Git and GitHub


## Project Description

The Municipal Financial Management System is a console-based C application developed to manage basic municipal financial and administrative information.

The system demonstrates programming concepts covered in PAP521S, including:

- Variables and data types
- Input and output
- Operators
- Decision making
- Loops
- Arrays
- Strings
- Functions
- Multi-file programming
- Input validation
- Searching
- Git and GitHub


## System Features

The system contains the following modules:

### 1. Employee Management

Allows the user to:

- Add employees
- Display employees
- Search employees by ID
- Calculate gross salary
- Store salary and allowance information


### 2. Budget Management

Allows the user to:

- Add departmental budgets
- Record expenditure
- Calculate remaining budget
- Identify departments that are within budget
- Identify departments that are over budget


### 3. Supplier Management

Allows the user to:

- Add suppliers
- Display suppliers
- Search suppliers
- Store supplier contact information


### 4. Asset Management

Allows the user to:

- Add municipal assets
- Display assets
- Search assets by ID
- Store asset value, department and condition


### 5. Reports

The system provides:

- Employee report
- Budget report
- Supplier report
- Asset report
